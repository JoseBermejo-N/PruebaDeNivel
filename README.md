
# 🚗 Prueba de Nivel: Sistema de Gestión de Concesionario

¡Bienvenido/a a este repositorio! Este proyecto consiste en una **prueba de nivel técnica** realizada en clase. El objetivo principal es poner en práctica los conceptos de Programación Orientada a Objetos (POO).

## 📋 Descripción del Problema

Se solicita diseñar e implementar un sistema para gestionar un **Concesionario de Vehículos**. El sistema debe cumplir con los siguientes requisitos:

### 1. Modelo de Datos (Coche)
De cada coche guardado en el concesionario se necesita almacenar la siguiente información:
* **Marca** (ej. Toyota, Ford, etc.)
* **Modelo** (ej. Yaris, Mustang, etc.)
* **Potencia** (en CV)
* **Consumo** (l/100km)
* **Combustible** (ej. Gasolina, Diésel, Eléctrico, Híbrido)

### 2. Datos de Entrada
El concesionario debe inicializarse con un **mínimo de 4 coches** con diferentes características para poder probar el sistema de manera efectiva.

### 3. Métodos y Lógica Requerida
El sistema debe implementar métodos específicos para resolver las siguientes consultas:
* ⛽ **Filtrar por combustible:** Retornar los coches que utilicen un tipo de combustible en concreto.
* ⚡ **Coche más potente:** Buscar y devolver el coche con la mayor potencia en el concesionario.
* 🐢 **Coche menos potente:** Buscar y devolver el coche con la menor potencia en el concesionario.

### 4. Ejecución del Programa
Desde el archivo o clase principal, se deben invocar todos los métodos anteriores y **mostrar los resultados por pantalla (consola)** de forma clara.


## 💻 Tecnologías Utilizadas

* **Lenguaje:** PHP
* **Paradigma:** Programación Orientada a Objetos (POO)
